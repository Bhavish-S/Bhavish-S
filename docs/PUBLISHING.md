# Publishing and maintenance

The profile uses GitHub-supported Markdown, HTML tables, expandable sections,
and local SVG artwork. `README.before-design.md` preserves the exact README
from before the redesign; `README.original.md` is also unchanged.

## Profile artwork and analytics

Run `python3 tools/design_profile.py` to rebuild the light/dark header, mobile
header, buttons, project status labels, and footer. The animation respects the
visitor's reduced-motion preference.

`Refresh profile cards` runs on its relevant file changes, manually, and daily
at 00:13 UTC. It writes the six exact `assets/stats/*.svg` paths used in the
README. It uses the repository's built-in `GITHUB_TOKEN`; no personal token is
needed for these cards. Language percentages use code bytes from public,
owned, non-fork repositories. API errors preserve the last successful cards.
Until its first successful run, the existing cards explicitly show that they
are waiting for data. No sample statistics are published.

The contribution snake uses the existing `output` branch generated by the
snake workflow. The 3D workflow refreshes `profile-3d-contrib/` daily. Generated
asset commits use `[skip ci]`, path filters, and concurrency groups to avoid
recursive runs and competing commits.

## Snake & Ladder

The game is in `game/`. It supports computer and two-player modes, exact-roll
wins, accessible turn announcements, reset, and small screens. It has no build
step, account requirement, or external JavaScript dependencies.

In repository **Settings → Pages → Build and deployment → Source**, choose
**GitHub Actions**. Run **Publish Snake & Ladder** if Pages was enabled after
the commit. The workflow publishes only the four game files at:

https://bhavish-s.github.io/Bhavish-S/game/

For local use, run `python3 -m http.server 8000` in the repository and open
http://localhost:8000/game/.

## Existing optional features

- Lowlighter's deep metrics need `METRICS_TOKEN`; the workflow skips with a
  clear explanation when the secret is missing. No credentials were added.
- WakaTime and Spotify remain optional, as described in the original content.
- The PGP block is still the original explicit placeholder, not a usable key.
- Existing third-party badges, trophies, and remote statistics remain subject
  to their providers' availability.
- The original `noc` and `Novic-Events` repository links could not be verified
  through the connected GitHub account. Their destinations were preserved.

## Checks performed

The redesign was checked for local image references, navigation anchors, SVG
XML validity, workflow YAML parsing, Markdown/diagram rendering, and original
README preservation. The game was checked across all 600 position/dice
combinations, plus snakes, ladders, overshoots, wins, and dice bounds. Browser
checks covered profile navigation, mobile width, computer turns, two-player
turns, mode changes, and reset. The analytics renderer was checked with isolated
fixtures for XML escaping, percentages, and empty-language data; fixtures were
not written to profile assets.
