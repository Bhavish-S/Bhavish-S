# Architecture & Telemetry Specification

## Core System Overview
This repository manages the automated profile telemetry, dynamic vector SVG generation, and continuous status tracking for Bhavish-S.

### Pipelines
1. **GitHub Profile 3D City**: Automatically updates isometric commit blocks every 24 hours.
2. **Snake Animation**: Compiles a snake feeding on contribution tiles every 12 hours.
3. **Telemetry Metrics**: Real-time stats calculation via GitHub GraphQL API.
