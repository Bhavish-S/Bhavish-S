# BHAVISH S — Design System: Cyber Editorial Dark

Reference for the dark engineering portfolio and cybersecurity identity.
Single source of truth: `src/styles/tokens.css` (Tailwind CSS v4 `@theme` block).

Stack: Vite 8.3 / React 19.3 / TypeScript 7 / Tailwind CSS v4 (CSS-first) / framer-motion 13.3 / Three.js 0.186.

## 1. Identity

**BUILD. SECURE. AUTOMATE.** A dark editorial canvas: near-black base (`#08090D`), card surface (`#0F1117`), electric emerald (`#00E5A8`), and cyber cyan (`#38BDF8`).

- Name: **BHAVISH S**
- Tagline: Cybersecurity Specialist & Automation Engineer · B.E. CSE at MITM
- Focus: Offensive Security · Threat Detection · DevSecOps · Intelligent Automation
- Fonts: **Inter** (display & body), **Space Grotesk** (headings), **JetBrains Mono** (labels, code, status)
- Electric Emerald (`#00E5A8`) & Cyber Cyan (`#38BDF8`) for verified status, security highlights, and technical nodes.

## 3. Sections

1. **Hero**: Cyber operator avatar with glowing status dot, high-impact headline, role lines, quick CTAs, and ambient Three.js aurora ribbons.
2. **StatementBand**: Editorial position band with academic focus, degree, and live availability.
3. **About**: About the Cybersecurity Engineer, philosophy (`BUILD. SECURE. AUTOMATE.`), 4 key focus pillars.
4. **Tactical Lab / Studio**: Interactive sandbox showcase for browser-based gamified training (`/game`).
5. **Work (Selected Projects)**: Horizontal scroll gallery with category filters and interactive architecture deep dives.
6. **Skills & Arsenal**: Categorized technical stacks (Offensive Security, Automation, DevSecOps, Backend, Databases, SIEM).
7. **Tech Marquee**: Animated infinite scrolling technology ticker.
8. **Contact & CTA**: Direct channel links (Email, GitHub, LinkedIn, Discord).
